# Original paintings for the scroll journey

All three assets were created with the built-in imagegen tool and optimized to WebP for this portfolio. They are original impressionist illustrations inspired by Claude Monet's palette and brushwork, not reproductions of specific paintings.

| Asset                                | Role                                                                | Exact prompt                              |
| ------------------------------------ | ------------------------------------------------------------------- | ----------------------------------------- |
| `public/images/water-lily-pond.webp` | Arrival and profile; the camera moves into a wide blue-green pond   | [Pond prompt](pond-artwork.md)            |
| `public/images/garden-bridge.webp`   | Projects and writing; the journey moves through a garden footbridge | [Bridge prompt](garden-bridge-artwork.md) |
| `public/images/lilies-close.webp`    | Conversation; an intimate close view of water lilies                | [Lilies prompt](lilies-close-artwork.md)  |
