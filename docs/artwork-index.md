# Original paintings for the scroll journey

All three assets were created with the built-in imagegen tool and optimized to WebP for this portfolio. They are original impressionist illustrations inspired by Claude Monet's palette and brushwork, not reproductions of specific paintings.

## Transparent foreground and mascot

- `public/images/monet-cat.webp`: original impressionist gray tabby with amber eyes and pearls. [Exact cat prompt](monet-cat-artwork.md).
- `public/images/willow-foreground.webp`: original transparent willow/wisteria foreground for depth. [Exact foliage prompt](willow-foreground-artwork.md).

Both use built-in imagegen and retain their alpha channel after WebP optimization. The retired vector cat source was removed.

## User portrait

`public/images/riska-portrait.webp` is a built-in imagegen style-transfer of the user-supplied beige-hijab photograph, preserving the face and pose in an impressionist garden setting. [Exact portrait prompt](riska-portrait-artwork.md).

## Project gallery covers

The five projects use distinct decorative cover studies, separate from the project screenshot field. Existing pond, bridge and lily paintings cover SIMDIKLAT, SIMFONI and MUSRENBANGKOM. New original imagegen assets `public/images/flower-study.webp` and `public/images/garden-path.webp` cover Classy and GoFit. Exact prompts: [flower study](flower-study-artwork.md), [garden path](garden-path-artwork.md). Every cover is labeled as an illustration; project details remain factual.

## Pringwulung location study

`public/images/pringwulung-monet.webp` replaces the generic garden-path cover for Pringwulung. Built-in imagegen transformed the owner's website screenshot into a standalone impressionist courtyard painting, without website UI. [Exact prompt and provenance](pringwulung-artwork.md).
